Case study: Gym membership website

GymFit

A bold, dark-themed gym site with tools members can actually use: a BMI calculator, a class schedule and a membership pricing modal.

The challenge

A gym site should do more than look good. It should let members check their BMI, browse classes and pick a plan.

Interactive features that actually work.

The biggest challenge wasn't the visuals. It was building interactive features that fit the brand and were useful.

The BMI calculator had to be accurate and match the dark theme, the schedule had to be scannable, and the membership modal had to guide people to a plan.

Key features

BMI calculator

Enter height and weight and get an instant reading with a category label.

Class schedule

A weekly schedule with times, trainers and class types, filterable by type.

Membership modal

Pricing tiers presented clearly, with plan comparison.

Dark and light mode

A toggle built with React state and Tailwind's dark mode utilities.

Process

  1. Visual direction

    Deep blacks, high-contrast type and orange accents to match the intensity of a fitness brand.

  2. Plan the features

    I mapped the BMI logic, schedule data structure and modal flow before writing code.

  3. Build components

    React, TypeScript and Vite, with each feature as its own component.

  4. Themes and responsive

    Added dark and light mode, then tested every feature across breakpoints.
